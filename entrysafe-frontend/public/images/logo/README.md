# EntrySafe Logo Assets

This folder contains the official EntrySafe branding assets.

## Expected Files

The following logo files should be placed in this directory:

### PNG Format
- `entrysafe-logo-full.png` - Full logo with text
- `entrysafe-logo-icon.png` - Icon/mark only

### SVG Format
- `entrysafe-logo-full.svg` - Full logo with text (scalable)
- `entrysafe-logo-icon.svg` - Icon/mark only (scalable)

## Logo Usage

- **Full Logo**: Use `entrysafe-logo-full` for primary branding on the website header and footer
- **Icon Only**: Use `entrysafe-logo-icon` for favicons, small UI elements, and social media
